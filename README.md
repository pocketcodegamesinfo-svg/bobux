# 🎮 Bobux

Игровая платформа, где каждый может создать свою игру, опубликовать её и играть с другими.

## 📋 Требования

- Node.js 20+

## 🚀 Установка

Открой `cmd` в папке проекта и выполни:

    npm install

## 🏃 Запуск

    npm run dev

- **Frontend:** http://localhost:3000
- **Backend:** http://localhost:4000

## 🏗️ Структура

- `frontend/` — клиент
- `backend/` — сервер
- `shared/` — общие константы
